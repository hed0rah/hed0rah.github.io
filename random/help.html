Windows Cleanup Command Reference

Elevated PowerShell required: Win+X, then A. Title bar must read Administrator.

Back up the user profile

robocopy[copy]
robocopy "$env:USERPROFILE" "D:\rescue" /E /R:1 /W:1 /XJ /XA:SH

/XJ prevents junction loops. Format the target exFAT; FAT32 fails silently over 4 GB. Copying from a Linux live stick is safer where practical.

Detect remote access software

Get-Process / Get-Service[copy]
$rat='anydesk|teamviewer|logmein|screenconnect|connectwise|supremo|ultraviewer|ammyy|gotoassist|splashtop|remotepc'
Get-Process | ? {$_.Name -match $rat} | Select Name,Path
Get-Service | ? {$_.Name -match $rat -or $_.DisplayName -match $rat} | Select Name,DisplayName,Status
Run first. These are legitimately signed commercial products, so antivirus does not flag them and they do not appear in malware scan results. Correlate any hit against the installed-programs list below: a service with no corresponding uninstall entry, or an install date inside the cluster identified there, indicates unattended deployment rather than deliberate installation.

List installed programs by install date

Get-ItemProperty[copy]
$k='HKLM:\Software\Microsoft\Windows\CurrentVersion\Uninstall\*',
   'HKLM:\Software\WOW6432Node\Microsoft\Windows\CurrentVersion\Uninstall\*',
   'HKCU:\Software\Microsoft\Windows\CurrentVersion\Uninstall\*'
Get-ItemProperty $k | ? DisplayName | Select DisplayName,Publisher,InstallDate |
  Sort InstallDate -Desc | Format-Table -AutoSize

A group of installations sharing one date identifies the incident. Treat the whole group as suspect regardless of publisher name.

Report registered security products

SecurityCenter2 / Get-MpComputerStatus[copy]
Get-CimInstance -Namespace root\SecurityCenter2 -ClassName AntiVirusProduct |
  Select displayName,pathToSignedProductExe
Get-MpComputerStatus | Select AMRunningMode,RealTimeProtectionEnabled,AntivirusEnabled

RealTimeProtectionEnabled : False indicates Defender was disabled by another product.

Enumerate startup items and scheduled tasks

Win32_StartupCommand / Get-ScheduledTask[copy]
Get-CimInstance Win32_StartupCommand | Select Name,Command,Location | Format-List
Get-ScheduledTask | ? {$_.TaskPath -notlike '\Microsoft\*'} |
  Select State,TaskPath,TaskName | Sort State | Format-Table -AutoSize

Persistence is more commonly in the task scheduler than in the Run key.

Inspect browser shortcuts for appended arguments

WScript.Shell[copy]
$w=New-Object -ComObject WScript.Shell
Get-ChildItem "$env:USERPROFILE\Desktop","$env:PUBLIC\Desktop" -Filter *.lnk -EA 0 |
  % { $s=$w.CreateShortcut($_.FullName)
      [pscustomobject]@{Name=$_.Name;Target=$s.TargetPath;Args=$s.Arguments} } |
  Format-Table -AutoSize

Args must be empty for a normal browser shortcut. A URL or --load-extension= reinstates the hijack at every launch.

Check proxy, DNS and hosts file

Internet Settings / DNS / hosts[copy]
Get-ItemProperty 'HKCU:\Software\Microsoft\Windows\CurrentVersion\Internet Settings' |
  Select ProxyEnable,ProxyServer,AutoConfigURL
Get-DnsClientServerAddress -AddressFamily IPv4 | ? ServerAddresses |
  Select InterfaceAlias,ServerAddresses
Get-Content $env:WINDIR\System32\drivers\etc\hosts | ? {$_ -notmatch '^\s*#' -and $_.Trim()}

A populated AutoConfigURL is a hijack. The hosts file should return no output.

Reset proxy and DNS

writes changes[copy]
Remove-ItemProperty 'HKCU:\Software\Microsoft\Windows\CurrentVersion\Internet Settings' -Name AutoConfigURL -EA 0
Set-ItemProperty 'HKCU:\Software\Microsoft\Windows\CurrentVersion\Internet Settings' -Name ProxyEnable -Value 0
Set-DnsClientServerAddress -InterfaceAlias '<alias from above>' -ResetServerAddresses

Find recently written executables

Get-ChildItem[copy]
Get-ChildItem $env:APPDATA,$env:LOCALAPPDATA,$env:ProgramData -Recurse -Include *.exe,*.dll -EA 0 |
  ? {$_.LastWriteTime -gt (Get-Date).AddDays(-60)} |
  Sort LastWriteTime -Desc | Select -First 40 LastWriteTime,FullName

Retrieve an uninstall string

UninstallString[copy]
Get-ItemProperty $k | ? {$_.DisplayName -like '*partial name*'} | Select DisplayName,UninstallString

Execute the returned string. MSI packages accept msiexec /x {GUID} /qn.

Re-enable Defender and scan

writes changes[copy]
Set-MpPreference -DisableRealtimeMonitoring $false
Update-MpSignature
Start-MpScan -ScanType QuickScan
Get-MpThreatDetection | Select -Last 20 ThreatID,InitialDetectionTime,Resources

Confirm patch level

Get-HotFix[copy]
Get-HotFix | Sort InstalledOn -Desc | Select -First 5

Removal sequence

  1. Uninstall the unwanted security product first. It obstructs removal and commonly holds Defender disabled.
  2. Run AdwCleaner. Add a Malwarebytes on-demand scan only if results are unclear.
  3. Run Autoruns with Options > Hide Microsoft entries. Review Logon and Scheduled Tasks.
  4. Re-enable Defender, update signatures, quick scan.
  5. Reset browser search engine, homepage and startup pages. Remove all extensions; restore an ad blocker only.
Carry tools on removable media rather than downloading them on the affected machine; a modified proxy or DNS can alter what is retrieved. Autoruns, Process Explorer and AdwCleaner require no installation.

Operational notes

  • A full-screen browser window exits with F11, then Esc. If the window persists, identify the owning process in Task Manager (Ctrl+Shift+Esc) and terminate it there. chrome.exe or msedge.exe indicates a web page rather than an installed application.
  • Session restore reinstates the previous tab set on next launch. Decline it, or clear Continue where you left off in browser settings first.
  • Two resident antivirus products produce scan conflicts, file-lock contention and substantially degraded I/O. Confirm only one is registered under SecurityCenter2.
  • Reinstalling the operating system discards the profile, the installed-program history and the persistence artifacts above. Enumerate before considering it.
