Five lines, one per rough layer of the stack - Application, Transport, Internet, Link, and a dashed Legacy line for the obscure/archaic stuff. Each station is a protocol; dashed connectors show which station depends on which one below it (DNS rides UDP, TCP rides IPv4/IPv6, and so on). Hover or click a station for details in the card; solid-filled stations have a full byte-level anatomy page, hollow ones are mapped but not built yet.
